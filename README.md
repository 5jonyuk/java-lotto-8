# java-lotto-precourse(로또)

## 💡 개요
이 프로그램은 간단한 **로또 발매기**를 구현한 콘솔 기반 애플리케이션입니다.  
사용자는 1000원 단위로 구입 금액을 입력하면 그에 해당하는 개수의 로또를 자동으로 발행받으며,  
입력한 **당첨 번호**와 **보너스 번호**를 기준으로 자신의 **당첨 내역과 수익률**을 확인할 수 있습니다.

예외 상황 발생 시, `[ERROR]`로 시작하는 명확한 에러 메시지를 출력하고  
입력을 다시 받을 수 있도록 설계되어 있습니다.

## 💡 기능 목록

### 1️⃣ 로또 구입
- 구입 금액을 입력받는다.
  - 구입 금액이 1,000원 단위가 아니면 예외 발생
    - 예) [ERROR] 구입 금액은 1,000원 단위여야 합니다.
  - 구입 금액이 0원 이하일 경우 예외 발생
    - 예) [ERROR] 구입 금액은 1,000원 이상이어야 합니다.
  

- 구매한 로또 수량을 출력한다.

---

### 2️⃣ 로또 발행

- 구입 금액만큼 로또를 발행한다.
- 한 로또는 1~45 범위의 중복되지 않은 6개의 숫자로 구성된다.
- 로또 번호는 오름차순으로 정렬한다.
- 발행한 로또 번호를 모두 출력한다.

---

### 3️⃣ 당첨 번호 입력
- 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다.
  - 숫자가 아닌 값이 포함되면 예외 발생
    - 예) [ERROR] 로또 번호는 숫자여야 합니다.
  - 중복된 번호가 있으면 예외 발생
    - 예) [ERROR] 로또 번호는 중복될 수 없습니다.
  - 1~45 범위를 벗어나면 예외 발생
    - 예) [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    

- 보너스 번호를 입력받는다.
  - 숫자가 아닌 경우 예외 발생
  - 1~45 범위를 벗어나면 예외 발생
  - 당첨 번호와 중복될 경우 예외 발생
    - 예) [ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.

---

### 4️⃣ 당첨 결과 계산
- 구매한 각 로또와 당첨 번호를 비교한다.
- 일치한 개수에 따라 당첨 등수를 결정한다.
  - 6개 일치 → 1등 (2,000,000,000원)
  -	5개 + 보너스 일치 → 2등 (30,000,000원)
  -	5개 일치 → 3등 (1,500,000원)
  -	4개 일치 → 4등 (50,000원)
  -	3개 일치 → 5등 (5,000원)
  -	그 외 → 낙첨
- 각 등수별 당첨 개수를 집계한다.

---
  
### 5️⃣ 결과 출력
- 당첨 통계를 출력한다.
- 수익률을 계산한다.
  - 수익률 = (총 당첨 금액 / 구입 금액) * 100
  - 수익률을 소수점 둘째 자리에서 반올림하여 출력한다.
    - 예) 총 수익률은 62.5%입니다.

---
**실행결과 예시**
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```
